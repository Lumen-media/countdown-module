# Countdown for Lumen

洗練されたフル機能のカウントダウンタイマーが、[Lumen](https://github.com/Lumen-media/lumen) の中にそのまま組み込まれます。放送、礼拝、イベントの大画面に表示 — 全画面でもコーナーオーバーレイでも、アプリから直接、好きな見た目と操作性で。

## できること

- **ライブで映し出す** — プレゼンター出力（全画面またはコーナー）および/または専用オーバーレイウィンドウにリアルタイムで同期して表示。
- **時間はおまかせ** — カウントダウン、カウントアップ、ゼロ以下への超過も可能。分・秒を正確に設定するか、クイックプリセット（`5 / 10 / 15 / 30` 分）を利用。
- **セットしたら放置OK** — 終了時に自動でキューを進める、完了音を鳴らす、画面から完全に隠す、も自由に。
- **タイミングでアクション** — タイムトリガーが指定の時刻にアクションを実行：画面のテキスト変更、サウンド再生、キューやスライドの進行、Webhook 送信まで。
- **見た目は自由自在** — フォント、色、グロー、プログレスバー、フリップクロックやパルスのアニメーションまで選択可能。変更内容は放送前にライブプレビューで確認。
- **ワークフローに溶け込む** — Lumen の Commander から起動・操作、ヘッダーのコンパクトなステータス表示、プリセットの保存も対応。

## クイックスタート

1. Lumen にモジュールをインストール（**設定 → モジュール → モジュールをインストール**）し、最新リリースの `.lumenpack` を選択します。
2. **ツール → カウントダウン** を開くか、`Ctrl+Shift+P` で `Countdown: Controls` を実行します。
3. 時間を設定し、見た目を選んで **開始** を押します。

## カスタマイズ

| 場所 | 調整できる内容 |
|---|---|
| **設定** | 時間、前後テキスト、クイックプリセット、背景スタイル、ホットキー |
| **外観** | フォント、色、グロー、数字アニメーション（なし / フリップ / ブラー）、パルス、プログレスバー、全画面またはコーナー位置 |
| **アクション** | 終了アクション（キュー進行、次のスライド、Webhook…）、タイムトリガー、完了音、マイナス時間 / カウントアップモード |

## 要件

- Lumen デスクトップアプリ
- ライブ制作、礼拝サービス、イベント向けに設計
