# Countdown for Lumen

A polished, full-featured countdown timer that lives right inside [Lumen](https://github.com/Lumen-media/lumen). Show it on the big screen during your broadcast, service, or event — fullscreen or as a corner overlay — with the look and control you want, right from the app.

## What it does for you

- **Live on air** — Renders on the presenter output (fullscreen or corner) and/or a dedicated overlay window, synced in real time.
- **Time it your way** — Count down, count up, or let it run past zero. Set exact minutes and seconds or use quick presets (`5 / 10 / 15 / 30` min).
- **Set it and forget it** — Auto-advance the queue when it finishes, play a completion sound, or hide it from the screen entirely.
- **React at the right moment** — Time triggers fire actions at exact timestamps: change the on-screen text, play a sound, advance the queue or slides, or hit a webhook.
- **Looks like you** — Pick fonts, colors, glow, progress bar, and even a flip-clock or pulse animation. Preview every change live before it goes on air.
- **Right in your flow** — Launch and control it from Lumen's Commander, watch the compact status in the header, and keep your presets saved between sessions.

## Quick start

1. Install the module in Lumen (**Settings → Modules → Install Module**) and select the `.lumenpack` from the latest release.
2. Open **Tools → Countdown** or press `Ctrl+Shift+P` and run `Countdown: Controls`.
3. Set your duration, pick how it looks, and hit **Start**.

## Personalize it

| Where | What you can adjust |
|---|---|
| **Configure** | Duration, pre/post text, quick presets, background style, and hotkeys |
| **Appearance** | Font, colors, glow, digit animation (none / flip / blur), pulse, progress bar, fullscreen or corner position |
| **Actions** | End action (advance queue, next slide, webhook…), time triggers, completion sound, negative time / count-up modes |

## Requirements

- Lumen desktop app
- Touched and loved for live productions, worship services, and events
